## 使った API

今回使った API は Github さんの

[List commit comments](https://docs.github.com/ja/rest/commits/comments?apiVersion=2022-11-28#list-commit-comments)

です。
Github を使ってるところまではオマージュ元と同じですが、よく見ると使っている API が違うことに気づくと思います。  
アップデートで特定コミットのコメントを取得できるようになったようです。  
1 つのコミットで 100 件までコメントを取得できるので、これで十分だと思います。
